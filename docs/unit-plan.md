### 설계 의도

| 관점 | 설계 내용 |
| --- | --- |
| 왜 가르치는가 | 3학년 사전 실태 조사 192명에서 음악과 자신의 삶을 잇는 장벽이 드러났다(M=2.73, 긍정 21.9%). 음악이 어떤 일터에서 어떤 가치를 만드는지 조사하고 말하는 경험으로 음악의 활용을 자기 삶의 언어로 옮긴다. |
| 도달의 증거 | 활동지 9문항과 1분 영상. 3~5번은 산업 조사, 6~8번은 활용 가치, 9번은 발표 원고를 확인한다. 7번에서 산업의 일과 음악의 가치를 연결하는 설명을 중점적으로 본다. |
| 학습 경로 | 12개 분야 둘러보기 → 고르기 → 서로 다른 두 곳 이상 조사 → 자기 말로 쓰기 → 세 문장으로 간추리기 → 1분 영상 발표 → 함께 보기 → 피드백·진로 연결 |
| 바람직한 어려움 | 자료집은 실마리만 제공한다. 학생은 음악이 사라진 상황을 상상하며 의미를 해석하고, 60초 안에서 무엇을 덜어낼지 스스로 정한다. |
| 피드백 | 1차시 저장본 확인 → 2차시 개별 안내·순회 질문·7번 짝 점검 → 3차시 자기 점검·재촬영·동료 질문 → 4차시 성취수준별 피드백 |
| 운영 문제의 해결 | 수업 시간에만 제출하도록 운영하고, 265명 규모의 현장 발표 부담을 개인별 1분 영상 제출로 줄인다. |

### 성취수준

‘조사하여’와 ‘발표한다’를 모두 수업 중 수행으로 확인한다. 산업의 이름과 대강의 내용을 옮기는 수준, 조사 내용을 자기 말로 설명하는 수준, 음악이 만드는 가치까지 밝히는 수준을 구분한다. 자료집 문장이나 AI 답변을 그대로 옮긴 답은 조사로 인정하지 않는다는 원안의 기준을 적용한다.

### 운영 설계와 적용 범위

원안은 ‘입장’과 ‘제출’의 두 통제로 수업 시간 안에서만 서버에 저장·제출하도록 설계했다. 결시자는 ‘다시 내기’를 허용해 별도 시간에 재작성한다. 265명이 1인 3분씩 발표하면 795분(13시간 15분)이 필요하므로, 개인별 1분 영상 제출로 발표 수행의 기회를 확보한다. **265명 전체 영상을 한 차시에 모두 시청한다는 뜻은 아니다.** 공동 시청 범위는 학급별 시간 안에서 정한다.

이 문서의 자동 저장·60초 자동 정지·자동 제출·수업 외 저장 제한은 원 설계안에 적힌 운영 방식이다. 제공된 플랫폼 ZIP에는 README에서 언급하는 서버 파일 `Code.gs`, `Video.gs` 등이 없어 서버 측 동작까지 검증하지 않았다. 실제 적용 전 해당 기능과 결시자 처리 시간을 확인한다.

| 학습목표 | 고른 음악 산업의 하는 일과 직업을 서로 다른 두 곳 이상에서 조사하여 자기 말로 정리하고, 음악의 활용 가치를 그 산업의 일과 이어 설명할 수 있다. |
| 성취기준 | [9음03-02] 음악과 관련된 산업에 대해 조사하여 발표한다. |
| 준비 자료 | 개인 태블릿, 음악 산업 탐구 플랫폼, 교사용 수업 통제·제출 현황 화면, 소리 유무를 비교할 게임 장면 |

| 단계 | 시간 | 교수·학습 활동 | 자료·유의점 |
| --- | ---: | --- | --- |
| 도입 | 6분 | 1차시 선택 분야 분포 확인. 게임 장면을 무음·유음으로 비교하며 “음악을 끄자 무엇이 사라졌나요?” 질문. 탐구 질문과 채점 기준 확인. | 미선정 학생 먼저 안내. 긴 답보다 산업과의 연결을 강조. 복사 금지, 조사처 두 곳 이상 안내. |
| 전개 ① 산업 조사 | 13분 | 제출을 열고 자료집의 하는 일·일의 흐름·직업을 출발점으로 조사. 3번 하는 일 2~3문장, 4번 직업 2가지 이상과 하는 일, 5번 조사처 작성. | 전개 32분 동안 제출 개방. “친구에게 말로 설명해 볼래?”로 자기 말 바꾸기 지원. |
| 전개 ② 활용 가치 | 12분 | 6번 구체적 활용 장면 → 7번 음악이 없으면 사라지는 것 → 짝 점검 2분 → 8번 나와의 연결. | 짝 점검 2분은 12분 안에 포함. “음악을 지우면 누가 곤란해질까?”로 되묻기. |
| 전개 ③ 핵심 세 문장 | 7분 | 9번에 ① 무슨 분야인가 ② 음악이 어떻게 쓰이는가 ③ 왜 중요한가 작성. 제출 후 완료 표시 확인. | 원안의 종료 시 자동 제출, 5분·1분 전 알림 활용. |
| 정리 | 7분 | 제출 닫기·미제출 확인. 희망자 2~3명이 “음악이 사라지면 ___이(가) 사라진다” 나누기. 다음 시간 1분 영상·동료평가 예고. | 수업 외 저장 제한 재안내. 결시자는 다시 내기 허용 후 별도 시간 재작성. |
| **합계** | **45분** | **도입 6 + 전개 32 + 정리 7** | |

## 6. 피드백 문장과 성찰

![함께 보고 질문하고 설명을 고치며 진로로 연결하기](../assets/illustrations/06-feedback.png)

아래 문장은 원안의 피드백 방향을 수업에서 바로 활용할 수 있도록 재구성한 보조 예시다. 학생 응답이나 실제 수업 결과를 인용한 것이 아니다.

| 상황 | 교사·동료의 질문 예시 |
| --- | --- |
| 자료를 그대로 옮겼을 때 | “화면을 잠시 덮고 친구에게 말로 설명해 볼래?” |
| 활용 가치가 개인 감상에 머물 때 | “그 일을 하는 사람에게 어떤 문제가 생길까?” |
| 7번을 짝과 점검할 때 | “네 설명에는 그 산업의 구체적인 일이 드러나니?” |
| 발표가 길어질 때 | “세 문장 중 친구가 꼭 기억해야 할 내용은 무엇일까?” |
| 진로로 연결할 때 | “이 분야에서 네 관심이나 강점을 활용할 수 있는 일은 무엇일까?” |
