## 원안에서 보존한 내용

- 교사·학교: 유정준 / 순천승평중학교.
- 대상과 시수: 중학교 3학년 음악, 총 4차시, 본시 2/4차시·45분.
- 성취기준: [9음03-02] 음악과 관련된 산업에 대해 조사하여 발표한다.
- 사전 조사: 192명, M=2.73, 긍정 21.9%. 사전 조사 집단과 운영 규모 265명은 서로 다른 수치로 구분했다.
- 결과물: 조사 활동지 9문항과 1분 발표 영상.
- 평가: 산업 조사 40점 / 음악의 활용 가치 30점 / 발표 수행 30점. 원안의 학기 성적 반영 비율 50%와 미응시·미제출 처리 문구도 상세 문서에 유지했다.
- 수행 조건: 서로 다른 조사처 2곳 이상, 직업 2가지 이상, 자기 말 2문장 이상, 발표 50초~1분.
- 본시 시간: 도입 6분 / 전개 13+12+7분 / 정리 7분. 짝 점검 2분은 활용 가치 탐구 12분에 포함했다.
